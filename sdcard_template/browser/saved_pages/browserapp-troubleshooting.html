BrowserApp Troubleshooting

Use this page when BrowserApp fetches a page but the result is blank, partial, unreadable, or missing expected links. BrowserApp intentionally favors bounded text extraction over full browser compatibility.

Fast Triage

  1. Confirm Wi-Fi is connected in NetworkApp.
  2. Retry with a simpler source page or direct article URL, not a home page.
  3. Check whether the target page depends on heavy JavaScript for core content.
  4. Check whether the page is mainly images/cards/video embeds instead of text.
  5. Try saving the page and reopening it from local storage if the fetch succeeded once.

Expected Limits

  • JavaScript-rendered page: may extract little or no content.
  • Image-heavy layout: text may be incomplete.
  • Complex multi-column site: reading order may collapse poorly.
  • Interactive controls only: BrowserApp is not a full browser.

Good Target Pages

  • single-article pages;
  • plain HTML notes and reports;
  • docs or explainers with one-column structure;
  • self-contained HTML files exported specifically for Cardputer.

Recommended Authoring Pattern

If a page is meant to be read on Cardputer, prefer the local single-file HTML contract and avoid required JavaScript, hidden critical content, and image-only meaning.
